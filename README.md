# Wanderstamp site

The website of [Wanderstamp](https://wanderstamp.app/), a sticker-book travel
tracker for Android: what the app is, its [privacy policy](https://wanderstamp.app/privacy.html)
and how to get in touch.

Plain HTML and CSS with no build step, served by GitHub Pages from the root of `main`.

| File | What it is |
|---|---|
| `index.html` | The one-page site |
| `privacy.html` | Privacy policy (linked from the Play Store listing) |
| `style.css` | Styles: the app's colours, Baloo 2 and Nunito from Google Fonts |
| `assets/` | App icon and favicon |
| `.nojekyll` | Tells GitHub Pages to serve the files as they are |

The source lives in the app repo's `site/` folder; edit it there and copy the files here.
